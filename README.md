//Git Lab Assignment Reflection



\# What I Learned

I learned the core workflow of Git, including branching, merging, and handling conflicts. Specifically, I learned that a merge conflict occurs when Git cannot automatically decide which change to keep because two different branches modified the exact same line of code.



\# Challenges Faced

The biggest challenge was understanding the conflict markers (<<<<<<<, =======, and >>>>>>>). Initially, it was confusing to see these in my source code, but I learned that I had to manually delete these markers and choose the correct version of the text before the merge could be finalized.



\# How Git Helps in Real Projects

In real-world software development, multiple people work on the same codebase simultaneously. Git prevents developers from accidentally overwriting each other's work. It ensures that every change is tracked and that conflicts are resolved intentionally, which improves software quality and team coordination.
